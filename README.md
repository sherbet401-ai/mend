A single-file CLI that applies the four edit formats AI agents emit: line-shifted unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls. Whitespace-tolerant matching in three tiers, all-or-none application across the whole edit set, and exit codes, stdout and result files that match SPEC.md exactly.

## Run it

```sh
node main.ts --edits edits.txt --root .
```
